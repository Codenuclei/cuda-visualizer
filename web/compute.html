01

A compute path, not a CUDA compiler.

These three vetted kernels execute real WGSL on WebGPU. Arbitrary CUDA source stays in the teaching interpreter; source-linked traces are not generated here.

02

No hidden speed claims.

The baseline is a direct JavaScript numeric loop, not optimized BLAS, native CUDA, or an entire application. Small workloads may be slower on a GPU. Browser adapters can use software.

03

Portable by capability.

WebGPU uses the adapter available to the browser, not a requested GPU brand. Unsupported devices use a labeled CPU path. No multi-GPU, tensor-core, or universal hardware certification is implied.
