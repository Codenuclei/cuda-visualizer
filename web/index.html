THE ARCHITECTURE SUITE

Four dedicated workbenches.
One unified microarchitecture model.

Whether you are optimizing low-level CUDA kernels, analyzing hardware roofline limits, or teaching GPU architecture, cuvis provides dedicated tools grounded in real hardware specifications.

01 / PARALLEL WORKBENCH

Interactive CUDA Playground

An in-browser CUDA C interpreter and execution stepper. Write or edit kernels, configure grid/block dimensions, and scrub through recorded execution step-by-step.

  • Step forward and backward with source-linked highlighting
  • 32-byte sector memory coalescing and request visualizer
  • Detect barrier synchronization deadlocks and race hazards
  • Inspect local variable state and final output buffers
Launch Playground →
02 / HARDWARE PROFILER

Accel-Sim Analytical Profiler

Hardware analysis derived straight from Accel-Sim and GPGPU-Sim hardware descriptions. Compares 8 classic parallel benchmark kernels across 10 GPU architectures.

  • Theoretical vs. achieved occupancy calculations per SM
  • Arithmetic intensity vs. DRAM bandwidth roofline curves
  • Cycle counts, IPC, and L1/L2 cache hit-rate modeling
  • Multi-kernel stream timeline with H2D and D2H PCIe staging
Open Hardware Profiler →
03 / SPATIAL EXPLORATION

3D Silicon & VR Architecture Lab

A screen-first 3D schematic of modern GPU silicon. Orbit through streaming multiprocessors, warp schedulers, register files, and tensor cores with WebGL2 and WebXR support.

  • Interactive 3D orbit, zoom, and component picking
  • Animated dataflow showing warp execution waves
  • Optional WebXR immersive VR mode for headset walkthroughs
  • Accessible perspective canvas fallback for all browsers
Explore 3D Silicon Lab →
04 / FRAMEWORK BRIDGING

Dynamic AI Library Explorer

Connect high-level machine learning code to verified CUDA implementations. Discover live npm packages via jsDelivr and trace operations down to bare-metal kernels.

  • Live package source discovery (TensorFlow.js, PyTorch, NumPy)
  • Static AST symbol extraction without running untrusted code
  • 8 verified CUDA teaching mappings (Softmax, Attention, LayerNorm)
  • Heatmaps for input, intermediate, and output tensor activations
