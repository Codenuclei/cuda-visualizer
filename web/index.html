      About this model

      where the numbers come from

      Hardware descriptions are parsed from the Accel-Sim framework's tested GPU configs (GPGPU-Sim 4.x format). Occupancy uses the CUDA occupancy calculator rules; durations use a roofline model with latency floors from the simulator's L1/SMEM/DRAM latencies. Stat names — gpu_tot_sim_cycle, gpu_ipc, gpu_occupancy, L2_BW — follow accel-sim's vocabulary, so a real simulation drops in seamlessly. Built with nvcc when CUDA 11–13 is present; analytical otherwise.
