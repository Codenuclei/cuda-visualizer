YOUR FIRST PARALLEL ADVENTURE
See what your code is doing.
A small, inspectable CUDA world. No GPU or language model needed.
  1. Pick a kernel. Make it yours.
    Explore fundamentals or a neural-network building block. Edit the source and set the grid and block sizes. The matrix example keeps its block y dimension at eight.
  2. Run it, then slow it down.
    The browser worker executes your kernel and captures a bounded trace. Play, scrub, or step with the arrow keys to follow actual source events.
  3. Connect code to the machine.
    Inspect threads, memory transactions, intermediate values, and output buffers. Explanations are rules applied to recorded state—not LLM predictions.
An honest model, not a hardware emulator.
This is a supported CUDA C subset, not nvcc. It models one- and two-dimensional launches, memory accesses, scalar math, branches, loops, atomics, and block barriers. Unsupported constructs produce errors. The map is a logical teaching view, not physical SM placement or cycle-accurate execution.
Neural-network examples are individual, small kernels—not full model inference. Coalescing is an access-based estimate. Shared-memory and scheduling behavior simplify real GPUs. Trace limits are displayed; long runs can be canceled. Built-in buffers use deterministic fixtures. New const pointer parameters receive a numeric ramp; new writable pointers receive zeros. Only n / N scalar parameters are configured by the launch inputs.
