Warp memory requests → DRAM sectors

      
run a kernel to inspect its global accesses (block 0)

      

      

      
32 lanes on top, 32-byte DRAM sectors below. A perfectly
        coalesced request touches ceil(bytes/32) sectors; scattered
        lanes fan out to many sectors and each one is a separate transaction.

    


    

      
Shared memory bank traffic

      
run a kernel that uses __shared__ to see bank pressure

      

      

      
Shared memory has 32 banks, 4 bytes wide. When several
        lanes of a warp hit different words in the same bank, the access
        serializes. Try the transpose preset with and without the
        +1 padding column.

    


    

      
Per-lane work inside each warp

      
run a kernel to see lane activity (block 0)

      

      
Each row is a warp, each cell a lane, shaded by how much
        work that lane did. A flat row is a happy warp; a striped row means
        divergent branches serialized the lanes. Try the divergence preset.
