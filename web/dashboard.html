      About this model

      where the numbers come from

      Hardware descriptions are parsed from the Accel-Sim framework's tested GPU configs (GPGPU-Sim 4.x format). Occupancy uses the CUDA occupancy calculator rules; durations use a roofline model with latency floors from the simulator's L1/SMEM/DRAM latencies. Stat names — gpu_tot_sim_cycle, gpu_ipc, gpu_occupancy, L2_BW — follow accel-sim's vocabulary, so a real simulation drops in seamlessly. Built with nvcc when CUDA 11–13 is present; analytical otherwise.

      the horizon

      Where cuvis goes next

      A living roadmap for the playground and profiler — every item stays GPU-free, deterministic and honest about what it models. The full list lives in docs/roadmap.md in the repository.

      shipping

      Device compare mode

      Pick two devices and see every chart side by side — the same kernel, two ceilings. Occupancy and roofline deltas are already per-device, so this is a UI story, not a model rewrite.

      next

      Imported trace view

      Drop in a real accel-sim trace summary (CSV of gpu_tot_sim_cycle-style stats) and replay it on the timeline, clearly labeled measured vs the analytic model.

      next

      Shareable dashboards

      Encode device + kernel selection in the URL hash so a dashboard view can be linked in a PR or classroom note — no server, no storage.

      next

      Kernel challenge cards

      Guided exercises: given a broken kernel (bad coalescing, bank conflicts), spot the bound on the roofline, then fix it in the playground and watch the chart move.

      later

      WebGPU reference mode

      An optional real-GPU run through WebGPU compute, used only to sanity-check the teaching model — never as a timing source.

      later

      Offline classroom pack

      A single self-contained export (PWA or file bundle) with the packs inlined so lessons run with no network at all.
